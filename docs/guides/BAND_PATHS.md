# 操作者指定能带路径

默认能带路径由程序自动生成（Setyawan–Curtarolo 约定，最终优化结构的标准原胞）。需要与 Wannier/紧束缚
或文献图对照时，可以自己指定路径。路径只在用户明确给出时使用；AI 只能建议，不会替你换路径。

## 写法

```
Γ-X-M-Γ|Z-R@60
```

- `-` 连接相邻点，`|` 断开成新的一段（图上画成 `X|Z` 并断线）。
- 段尾 `@N`：这一段每条线的点数（2–200），覆盖默认 40。各段点数相同时写 VASP 线模式 KPOINTS，不同时写显式 k 点列表。
- 标签按约定查表：`Γ`、`G`、`GAMMA`、`\Gamma` 等价；下标写 `Σ1`、`SIGMA_1`、`Σ_1` 均可。
- 前缀 `hinuma:` 改用 Hinuma（seekpath）标签，坐标仍换算到同一个能带原胞，不改 SCF 晶胞；
  `latimer_munro` 不支持（其标签是程序生成的字母）。
- 显式点 `名称(a,b,c)`：分数坐标基于**能带/SCF 所用晶胞**（`scf/POSCAR` = `bands/POSCAR`，即优化结构的
  Setyawan–Curtarolo 标准原胞）的倒格子基矢。
- 二维 slab 只支持自动面内路径（晶胞未标准化）。

未知标签会被拒绝，并列出该晶格可用的标签；格式错误同样在写任何文件前拒绝。

## 两个入口

1. **新任务**：在参数方案里给出 `band_path`（`propose_scan_plan`；命令行 `prepare --band-path`）。
   准备时只按输入结构预检标签；SCF 完成后在最终晶胞上解析，bands 审阅显示每个点的分数和笛卡尔坐标，
   运行前再比对一次。
2. **已有任务换路径**：`prepare_bands_path`（来源任务 SCF 已通过）。在新目录复制并逐一校验到 SCF 为止的
   全部证据（含 `scf/CHGCAR` 对 `complete.json` 的 `charge_sha256`），不改来源、不重算 SCF，新任务停在
   bands 审阅，需要重新审阅和单独提交授权。部署引擎不支持时明确拒绝，不会退回自动路径。

结果里 `bands-path.json` 记录实际运行的路径；`report.json` 的 `band_path_source`/`band_path` 和
`bands.csv` 末尾新增的 `k_label`、`path_source` 两列记录路径来源（原有列不变）。

## 例：La2CuO4（HTT，I4/mmm）

体心四方在 Setyawan–Curtarolo 约定下分两类，按惯用晶胞 c 与 a 的大小：

| 类型 | 条件 | 可用标签 |
|---|---|---|
| BCT1 | c < a | Γ、M、N、P、X、Z、Z_1 |
| BCT2 | c > a | Γ、N、P、Σ、Σ_1、X、Y、Y_1、Z |

La2CuO4 的 c ≈ 13.2 Å > a ≈ 3.81 Å，是 **BCT2**，没有 `M` 标签，所以 `Γ-X-M-Γ` 会被拒绝。注意 BCT2 的
`X` = (0,0,½)（原胞倒格子分数）在笛卡尔坐标里是 (π/a, π/a, 0)，即 CuO2 面四方记号中的 M 点。

按 CuO2 面记号（X = (π/a,0,0)，M = (π/a,π/a,0)，便于和 Wannier 模型对照）重做
`La2CuO4_HTT_Cu_pv_780_ions_32c` 的能带：

```
prepare_bands_path  source_job=La2CuO4_HTT_Cu_pv_780_ions_32c  job_name=La2CuO4_HTT_GXMG
band_path = Γ-X(-0.25,0.25,0.25)-M(0,0,0.5)-Γ
```

或在对话里直接说：“把 La2CuO4_HTT_Cu_pv_780_ions_32c 的能带按 Γ-X(-0.25,0.25,0.25)-M(0,0,0.5)-Γ 重做，新任务名
La2CuO4_HTT_GXMG”。然后 `get_stage_review` 核对解析出的坐标（应为 X → (0.825, 0, 0) Å⁻¹，
M → (0.825, 0.825, 0) Å⁻¹），记录审阅，再申请提交。

只用 BCT2 自身标签的例子：`Γ-X-P-N-Γ-Z`。

## 对第一次能带图不满意：从候选里选

说“换个路径”或“这张图不好”时，AI 调用 `request_band_path_choice`，程序在来源任务的能带原胞上生成候选，
每条都经过与操作者路径相同的校验和解析，解析不了的不列出（菜单底部写明原因）：

1. 自动（Setyawan–Curtarolo），`*` 标记第一次计算所用路径；
2. Hinuma（seekpath，服务器装有 seekpath 时）；
3. 层状面内路径：标准惯用晶胞 c/max(a,b) ≥ 2.5 时（约 1.5 倍理想 hcp 比值，层状铜氧化物约 3–3.5），
   沿二维子晶格走 Γ–X–M–Γ（或六角 Γ–M–K–Γ、矩形 Γ–X–S–Y–Γ），再加一段到 c* 轴上的高对称点；
4. 靠近第一次结果中 E_F 交叉（绝缘体为 VBM/CBM）的高对称点——只依据已采样路径，不是全布里渊区搜索；
5. AI 至多附一条建议，同样校验并标为“AI 建议”。

操作者输入编号、`c`（自定义，无效会重问，不写文件）或 `q`。选定后新建 `<来源>_path<编号>`，复用 SCF，
仍需审阅 bands 并单独授权提交。模型不能代选；非交互模式只返回候选。

La2CuO4_HTT_Cu_pv_780_ions_32c（BCT2）的候选：

| 编号 | 来源 | k 点 | 路径 |
|---|---|---|---|
| 1* | 自动 SC | 440 | Γ-X-Y-Σ-Γ-Z-Σ_1-N-P-Y_1-Z\|X-P |
| 2 | Hinuma | 360 | hinuma:Γ-X-P-N-Γ-M-S\|S_0-Γ\|X-R\|G-M |
| 3 | 层状面内 | 160 | Γ-X(-0.25,0.25,0.25)-M(0,0,0.5)-Γ-Z |
| 4 | 交叉/带边 | 120 | Γ-Σ-N-Z |
