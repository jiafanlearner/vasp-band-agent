# 按任务选择赝势变体

预览及提出方案工具增加 potential_variants 参数，例如：

```json
[{"element": "Cu", "variant": "Cu_pv"}]
```

它只覆盖本次新任务的库映射，不修改 potentials.toml 或旧任务。未指定元素沿用库映射；
若要求 La、O 与旧任务完全一致，先读取旧任务的选择记录，再显式指定各元素变体并核对哈希。
拒绝重复元素、不属于结构的元素、越界路径、错元素变体、缺失文件；不会回退默认赝势。

选择随参数方案保存，预览签名绑定选择和实际合并 POTCAR 哈希。
库内容或选择发生变化时原方案不能继续准备。准备记录保存各项来源、标题、ZVAL、ENMAX 和哈希。
显式选择时检查 NBANDS 至少容纳中性非磁性体系的占据电子；这只是容量下限，
仍需空带余量及实际占据验收，不能证明科学适用性。

自然语言示例：
“在新任务中使用 Cu_pv，La 和 O 与原任务保持一致。先预览赝势元数据、NBANDS 和扫描方案，不提交。”

重启本地 Agent；远程准备需先部署新版计算引擎。旧 release 会明确拒绝变体请求。
更换赝势后重新验证 ENCUT 和 k 网格，不通过选择性重试沿用旧赝势收敛证据。
本次开发没有远程部署或提交。测试仅使用合成赝势和模拟接口。
