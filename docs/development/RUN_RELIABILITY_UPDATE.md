# Si 实跑后的可靠性修复（2026-09-27）

## 本次实现

- 远程 prepare/preview 在登录节点加载已配置环境，只解析 `vasp_std`，不启动 VASP。记录环境脚本、实际可执行文件及其 SHA-256。路径或脚本包含 FixZ/IOPTCELL 标记且请求完整晶胞优化时停止；没有标记仅表示未检出，不能证明二进制未修改。
- 提交前复查环境指纹；计算节点运行前再次验证实际 `vasp_std` 指纹。指纹变化要求新任务重新验证。收敛复用要求来源任务有环境指纹且二进制一致；旧任务无指纹不能自动推断来源环境。
- 优化验收失败时保存 `relaxation-diagnostic.json`：失败阶段、原因、力/应力、前后晶格、离子步数和电子/离子排查提示。仍按原阈值停止，不自动放宽。
- 仅为已保存远程工作目录内的指定阶段开放 `inputs.json`/`complete.json` 读取；支持环境和优化诊断摘要。任意位置的 JSON、POTCAR 和密钥仍不开放。
- 大于6000字符的工具结果在模型上下文中投影为有限摘要，包括最近四轮。完整输出留在原会话及 `.context-evidence/<sha256>.json`；`read_context_evidence` 可按3500字符分页读取并校验哈希。摘要明确是历史、可能不完整，不能充当当前权限或验收通过的证据。`--context-chars 0` 仍关闭压缩。
- 最终能带验收检查全路径本征值/占据是否有限、通道尺寸是否一致、是否每个路径点最高带均为空；不能据此保证任意高能窗口覆盖。
- 非金属图以VBM为零，金属图以SCF费米能为零；纵轴明确参考。报告记录参考能，CSV保留原SCF费米参考列，并增加绘图参考列，避免破坏旧数据使用方式。
- 下载生成 `download-receipt.json`，列出逐文件已验证的SHA-256。下载完整性与科学验收仍分开。

## 使用与边界

### 第三轮：断线恢复与集群回归

- 每次操作者确认资源后生成操作编号，远程资源配置全部写入完成才保存 `resource-change.json` 回执。响应丢失后，只读核对编号、阶段、配置签名、实际资源及当前授权；匹配则恢复，不再询问相同资源。缺少匹配回执时明确停止，不自动重放配置写入。
- 提交响应丢失后，只读查询远程提交记录；存在真实job_id则返回已登记结果，记录仍为uncertain则保持不确定，禁止重复sbatch。提交次数仍按原逻辑消费。
- 完全相同的阶段审阅重试返回已有记录，不重复增加审阅历史。
- 新增 `check_remote_environment` 只读工具，不运行VASP、不提交。
- 上述确认缓存仅限当前进程/授权；重启或切换会话不继承提交授权。没有把“用户曾确认”升级为永久自动提交许可。

### 第二轮：资源、调度状态与交付

- 提交表单的程序默认值会适配当前授权的核数、节点、分区和时限；不会默认沿用旧任务超出上限的96核等配置。建议并发数也不超过执行清单中的测试数。仍由操作者确认实际申请量。
- `remote_status` 保留 squeue/sacct 查询错误，squeue失败后尝试sacct；两者均无有效记录时明确返回 `scheduler_status_known=false`。查询失败不等于作业完成，也不触发重新提交。
- 下载增加 `delivery-summary.json`。只有完成状态、四阶段检查点、能带验收记录和必需图表文件齐备才标记 `complete_package`；缺失、旧版报告或部分输出标记 `partial_or_unverified`，列出原因，仍允许下载排障资料。
- 验证：完整回归252项通过；随后新增调度查询失败/回退场景，针对性9项通过。测试使用模拟调度器，未提交真实计算。

重启本地Agent即可使用上下文、工具读取和下载改进。新的远程计算引擎需要执行remote_deploy后用于新任务；已绑定旧release的任务不会自动迁移，也没有改写已完成Si计算。旧图片不会被静默重画。

环境预检主要识别已知标记并绑定文件指纹，不保证发现所有私有补丁；模块依赖库变更也不完全由二进制哈希覆盖。旧任务无环境记录时首次提交会新增记录并使旧审阅快照失效，应重新读取和记录审阅。

此次未实现全自动更换VASP安装、放宽阈值、自动部署旧任务或后台自动提交。最终完整科学解释和图像人工式核验仍由Agent/操作者完成。
